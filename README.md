# Martha Wambui Thuku — Professional Portfolio

## Publish on GitHub Pages

1. Extract the ZIP.
2. Upload the extracted contents directly to your GitHub repository root, keeping the `assets` directory together with `index.html`, `styles.css`, `script.js` and `.nojekyll`.
3. In **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/ (root)**, then save.
4. Open the published URL shown by GitHub when deployment completes.

No installation, compilation, paid services, API keys or framework runtime is required. Relative paths support repository subdirectories. You can also open `index.html` directly to preview the page; copying an email automatically generally requires HTTPS or localhost.

## Technology and usability

- Semantic HTML, responsive CSS Grid/Flexbox, and modern JavaScript.
- Responsive WebP portrait sizes with declared image dimensions and high fetch priority.
- One local stylesheet and one deferred script; no third-party fonts, tracking or libraries.
- Keyboard-accessible mobile navigation, visible focus styles, skip navigation, status announcements and reduced-motion support.
- Content and mobile navigation remain available when JavaScript is disabled.
- Filterable technology list, CV download, email/phone links, contact-card download and clipboard action with manual-copy fallback.
- Passive scroll listener with animation-frame scheduling for progress and active navigation.
- Print styles, high-contrast mode adjustments, structured Person metadata and social-sharing tags.

## Editing

Update text in `index.html`, presentation in `styles.css` and interactions in `script.js`. Replace the PDF in `assets/Martha_Wambui_Thuku_CV.pdf` when updating the CV. The portrait is AI-edited from the supplied photograph. Its responsive variants are named `martha-professional-480.webp`, `martha-professional-800.webp` and `martha-professional-1120.webp`.
